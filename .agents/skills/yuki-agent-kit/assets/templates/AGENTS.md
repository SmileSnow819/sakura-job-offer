# AGENTS.md

修改产品行为前先阅读 `PRODUCT.md`。

## 工作规则

- 优先选择能满足产品目标的最小改动。
- 不要自行发明产品需求、用户角色、集成方式或数据保留规则。
- 改动会扩大产品范围、实质改变公开行为，或导致不可逆的数据变化时，先说明并请求决定。
- 保持代码、测试和用户文档一致。
- 非直觉的架构决定、重要的被拒绝方案，或未来很可能重新讨论的决定，应写入 Agent Note。
- 运行与改动范围匹配的检查；没有实际运行的命令不得声称通过。

## 文档语言

- 默认使用中文撰写产品、开发和 Agent 协作文件。
- 只有面向外部用户或开源协作者、且确有双语读者的 README / 文档才需要中英双文。
- 双语文档使用独立文件：README 默认中文 `README.md`，英文版为 `README.en.md`；已有项目遵循其现有命名约定，不得在同一文档混合中英文 prose。
- 修改双语文档时，必须在同一改动中更新对应文件，并保持标题、列表、代码块、链接和事实含义一致。
